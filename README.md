# 🛡️ Care-Your-System

A simple and effective utility to maintain your Windows system's health.

### 🚀 What it does:
* **System Scan:** Checks for file corruption using standard `DISM` and `SFC` commands.
* **Security:** Triggers a Windows Defender scan to check main system areas for malware.
* **Native:** Runs directly through the Windows Command Prompt.

### ⚠️ Important Instructions:
1. **Run as Administrator:** This tool requires admin access to perform system-level repairs.
2. **EXE Version:** If you are using the `.exe` version, Windows may show a "SmartScreen" warning. Click **"More Info"** and then **"Run Anyway"**—this is a common false positive for batch-converted files.
